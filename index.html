フリースクール　・　横浜市北部　・　小学生・中学生

フリースクール
子どもの寄り道基地

学校とは別の、もう一つの居場所。
行けない日があってもいい。
勉強しなくてもいい。
まずは、安心して過ごせる場所をつくりたい。

01

こんな子どもをイメージしています

学校に行けない、あるいは行くこと自体がとても負担な小中学生。家ではゲームや動画、読書で過ごしていて、外との接点が減っている。人とは関われるけれど、集団生活はしんどい。そんな子が、無理なく外とつながれる場所です。

  • 不登校・登校しぶり
  • 学校には行けないが、外出はできる
  • 勉強を強制されるのがつらい
  • 少人数なら人と関われる
  • 横浜市：港北区・都筑区・神奈川区・鶴見区　川崎市：中原区　あたり

医療や福祉の専門支援が必要な場合は、この場所だけで抱え込まず、専門機関につなぐ想定です。

02

合わせるのは、子どもではなく場所のほう

子どもを施設に合わせるのではなく、
子ども自身が選べる選択肢を、こちらが用意する。

しないこと

  • 学校復帰の強制
  • 毎日通わなければいけないルール
  • 全員同じ学習時間
  • ゲームやスマホの一律禁止
  • 「何もしない＝失敗」という見方

大事にすること

  • 安心できる居場所であること
  • 何もしない日があってもいいこと
  • 興味のあることから始められること
  • 人・学び・社会と、ゆるくつながること
  • 他人を傷つけない、最低限のルール

03

好きなことが、入口になる

勉強させる場所ではありません。好きなことをしているうちに、自然と人と学びと社会につながっていく場所を目指します。

ゲームが好き

Minecraft → プログラミング → ゲーム制作 → 動画 → IT

料理が好き

買い物 → 予算・原価 → レシピ → 販売体験

植物が好き

栽培 → 記録 → 収穫 → 販売 → 売上の感覚

パソコンが好き

タイピング → AI → Web → 動画 → 職業体験

学習は全員必須ではありません。「今日はやらない」も、「高校のために数学をやりたい」も、どちらも尊重します。AIを使った自学も、スタッフが横で支える形を考えています。

04

平日は居場所、週末は外へ

平日のイメージ

固定時間割ではなく、その日の調子で変えます。

  1. 10:00登所・準備
  2. 10:30自由活動（読書、ゲーム、工作、雑談、何もしない）
  3. 12:00昼食
  4. 13:00選択型の活動
  5. 15:00学習・PC・創作など
  6. 16:30振り返り・自由時間
  7. 17:00帰宅

時間の目安は、居場所が半分以上。学びや社会との接点は1〜2割くらい。

週末は、場所から出る

月1回を基本。釣り、BBQ、キャンプ、工場見学、博物館、科学館、料理、プログラミングなど。

平日は「ここにいていい」場所。週末は「普段と違う景色に触れる」時間。両方あって、はじめて居場所が閉じてしまわないと考えています。

05

最初から大きくしない

大きな施設にたくさんの子どもを集める、という始め方はしません。小さく開いて、選んでもらえるかどうかを確かめてから広げます。

  • 規模 定員 10〜15人　／　同じ日に来る子は 5〜8人くらい
  • 時間 週4〜5日　10:00〜17:00 くらい（初期はもっと少なくてもよい）
いま競合やニーズを調べる
次3〜5人で小さく試す
その先10〜15人の本格運営へ

善意だけでは続かないので、利用料を基本に、学習支援や週末の体験、一般向けの教室なども組み合わせて、事業として回る形を目指します。
